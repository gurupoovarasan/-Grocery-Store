# 🛒 Grocery Store Website

A responsive and user-friendly Grocery Store website developed using HTML, CSS, and JavaScript. The website provides customers with a simple and attractive interface to explore grocery products, offers, testimonials, blogs, and contact information.

## 🚀 Features

- 🏠 Home page with attractive banner
- 🛍️ Product listing and product details
- 🥦 Grocery categories and products
- 🎁 Special offers section
- ⭐ Customer testimonials
- 📝 Grocery-related blog section
- 📞 Contact page
- 🤖 AI-powered customer chatbot using Google Gemini API
- 📱 Responsive design for different screen sizes
- 🎨 Modern and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
